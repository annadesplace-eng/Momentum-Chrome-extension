# Hello Anna

A calm Chrome new tab page: clock, today's calendar, weather, world clocks, top 3 priorities, a daily news brief, and a daily background photo.

## Features

- **Today's calendar**: paste any `webcal://` or `https://` .ics link (for example an iCloud shared calendar) under ⚙.
- **Weather**: from Open-Meteo, no API key needed. Click it to change the city.
- **World clocks**: Paris, London, New York.
- **Top 3 today**: three priorities that reset each morning.
- **Daily brief**: fashion business, trends and startup headlines from RSS feeds, with topics several outlets are covering.
- **Background**: a London photo from Wikimedia Commons or Bing's photo of the day.

All settings are kept locally in `chrome.storage`. Nothing is sent anywhere except the feeds and APIs above.

## Install

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select this folder.
4. Open a new tab.
